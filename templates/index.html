How It Works

Standard Softmax: exp(x) / Σexp(x) — Biased towards larger values due to exponential amplification.

Modified Softmax: σ(x) / Σσ(x) — Uses sigmoid, treats all "good" values equally (sigmoid saturation).

Weighted Modified: σ(αx) / Σσ(αx) — Tunable α controls sensitivity. Lower α = more distinction preserved.
